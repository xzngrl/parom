# ПАРОМЪ — концепт лендинга

Статический одностраничный сайт на HTML, CSS и JavaScript. Для просмотра откройте `index.html` в браузере. Шрифты загружаются из Google Fonts, фотографии — с Unsplash и Pexels, поэтому для их загрузки требуется подключение к интернету.

Все тарифы и сведения о комплексе, адресе, телефоне, графике и характеристиках помещений в проекте демонстрационные. Форма проверяет поля в браузере и показывает только локальное демо-подтверждение: данные не отправляются.

## Файлы

- `index.html` — семантическая разметка и метаданные.
- `styles.css` — визуальная система, макеты и адаптивные состояния.
- `script.js` — мобильная навигация, появление секций, lightbox и валидация формы.
- `favicon.svg` — знак сайта.
